## Development Workflow

1. **Environment Setup**

    ```bash
    cp .env.example .env       # Copy default env file
    php artisan key:generate   # Generate app key
    ```

2. **Database Initialization**

    ```bash
    # Ensure MySQL is running locally
    mysql -u root -p          # Enter password if set
    CREATE DATABASE resto_tkmr_lokal CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    exit

    # Run migrations
    php artisan migrate:fresh --seed
    ```

3. **Running the Application**

    ```bash
    php artisan serve          # Starts Laravel dev server at http://localhost:8000
    ```

4. **Testing & Linting**
    ```bash
    phpunit                    # Run test suite
    ```
